# 🚴‍♂️ Samokat Shift Tracker

Легкое и эффективное консольное приложение для курьеров сервиса «Самокат», позволяющее вести детальный учет рабочих смен, рассчитывать заработок и управлять историей выплат.

Этот проект создан как **Pet-проект** для отработки навыков построения надежной архитектуры и работы с реляционными базами данных на Python.

---

## 🛠 Технологический стек

В проекте реализован полноценный **CRUD** цикл с использованием следующих технологий:

* **Python 3.x** — основная логика приложения.
* **SQLite3** — в качестве надежного и портативного хранилища данных.
* **RegEx (re)** — для строгой валидации ввода дат в формате ДД-ММ-ГГГГ.
* **Модульная архитектура** — разделение проекта на `main.py` (UI/UX) и `logic.py` (Business Logic & DB Operations).

---

## 🚀 Основные возможности

* ✅ **Учет смен:** Добавление даты, часов, количества «стопов», заказов SLI30 и надбавок за погоду.
* 📊 **Аналитика:** Автоматический расчет заработка за каждую смену и общая статистика по часам и деньгам за всё время.
* 🔄 **Управление данными:** Удаление и редактирование существующих записей по уникальному `id`.
* 🛡 **Безопасность данных:** Реализована защита от "дурака" — валидация типов данных и проверка на отрицательные значения.
